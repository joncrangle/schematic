# GitHub workflow

Issues and specs live in `joncrangle/schematic` on GitHub. Use `gh` from this clone,
or pass `--repo joncrangle/schematic`. Write multiline issue or comment bodies to a
file and pass `--body-file`.

When a skill says "publish to the issue tracker", create a GitHub issue. When
it says "fetch the relevant ticket", read the issue and its comments. GitHub
shares issue and PR numbers; resolve a bare reference before acting on it.
External PRs are not feature-request tickets for issue triage.

For issue triage, use [canonical labels](triage-labels.md).
