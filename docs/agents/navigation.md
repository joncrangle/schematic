# Task navigation

Match the rider symptom or task to an entry point below. The paths are starting
points for discovery, not a complete directory inventory.

## Which card is failing?

[StationPopover](../../src/components/map/StationPopover.tsx) and
[StationDeparturesSection](../../src/components/nearby/StationDeparturesSection.tsx)
serve schematic station cards through the station-departure path.
[StopDetailsPopover](../../src/components/map/StopDetailsPopover.tsx) serves feed
stop selections in targeted route mode. Confirm which card the rider means
before following its fetch and selection handlers.
